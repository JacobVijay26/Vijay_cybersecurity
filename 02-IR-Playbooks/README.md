# Incident Response Playbooks

This folder contains incident response playbooks following the NIST SP 800-61 framework.

## Playbooks

- **Ransomware Response Playbook** — Complete IR playbook covering detection, containment, eradication, recovery, and lessons learned phases. Includes IOC detection signatures, SIEM alert rules, Wireshark filters, and communication templates.

## Framework

NIST SP 800-61 Rev 2
